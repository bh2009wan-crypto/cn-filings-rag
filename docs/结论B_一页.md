# 作业 B 一页结论：用茅台财报训一个「董秘」

> **最终用的是本机方案**（Apple M2 / MPS），不是 Colab。原因见文末「为什么不在 Colab 跑」。
> 基座：**Qwen3-0.6B**（课件用 Qwen3.5-2B，8GB 内存训不动 2B）；四格定义与判分口径与
> `notebooks/maotai_dongmi_lora.ipynb` 完全一致，两个结果可直接对比。

## 一、语料与数据（做了什么）

| 项 | 数值 |
|---|---|
| 语料 | 贵州茅台 **11 份**：2021–2025 年报 + 2021H1–2026H1 半年报（2026 年报尚未披露，约 2027-04 才出） |
| 规模 | 1,292 页 / 48.8 万字正文 / 2,238 张表 → 4,405 块 |
| 造数据 | 一块原文 → 3 组「投资者提问 → 董秘作答」；**强制逐字抄出「依据原文」**（让"编造"变成可字符串校验的） |
| 生成 | 180 + 52 + 92 块，共 **357 条问答**，约 5 分钟（deepseek-flash，8 并发，关闭 thinking） |
| 质检 | 阶段一（脚本）：依据覆盖率 < 0.9、答案含原文没有的数字、问题像考试题 → 淘汰 6 条；<br>阶段二（模型）：判「有据 0/1/2 · 自然 0/1」→ **留 312 条**（保留率 87%，全部「有据 2 且 自然 1」） |
| 划分 | **按块（事实）85/15**：训练 **262 条（97 块）/ 测试 50 条（18 块）**，测试覆盖全部 10 个报告期 |
| 换问法 | 训练集 **257 条**、测试集 **46 条**（3-gram Jaccard < 0.5 才算"换了"） |
| 人工抽检 | 固定种子 `20260924`、分层抽 **40 条** → `data/sft/review_40.csv`（含块原文，不用翻 PDF 就能判；**这一步留给你终审**） |

## 二、训练（本机 M2，8GB 内存）

| 项 | 数值 |
|---|---|
| 基座 | Qwen3-0.6B（0.61B 参数），主干 **bf16** / LoRA 适配器 **fp32**（peft 自动保持） |
| LoRA | r=16、alpha=32、dropout=0.05，target_modules = q/k/v/o/gate/up/down_proj（**探针读出来的，不是抄教程**） |
| 可训练参数 | **10.09M / 0.61B = 1.67%** |
| 训练 | 3 epoch、**51 步**、lr 2e-4、batch 1 × 梯度累积 16、序列上限 192 |
| 耗时 | **526 秒（8.8 分钟）**；loss 3.05 → 0.86（逐批有波动，趋势明显下降） |
| 四格评估 | 每格 60 条（测试格 50/46 全量）+ RAG 对照 50 条；两次评估各约 8 分钟 |

> 两个工程决定值得记：① **M2 上 bf16 比 fp32 快 11 倍**（实测 0.9s vs 10.0s/批）；
> ② 评估与训练必须**分进程**跑，否则 8GB 内存会被 MPS 缓存 + 激活值撑爆（第一次跑就 OOM 了）。

|---|---|---|---|---|---|---|---|

| 格4 没训练过·换问法 | 46 | 0.092 | 0.172 | 2.19 | 0.88 | 0.00（13 题） | 0 → 0 |

## 四、这些数字说明什么（这才是重点）

**✅ 训练确实改变了行为，方向也对**

1. **学会了「董秘口吻」**：最明显的证据是长度比 3.35 → 1.03——训练前模型啰嗦（输出是金答案的 3 倍长），训练后长度基本对齐。逐条看更直白：
   - 训练前："2021年半年度报告中，**公司未披露**被控股股东及其关联方非经营性占用资金的情况……"
   - 训练后："**这两项都没有。**被控股股东及其关联方非经营性占用资金的情况是**不适用的**……"（这一条 F1 = 0.59）
   - 第一人称、先给结论、用"不适用"这类公告口径——**这正是课件说的「学会怎么答」**。
2. **格1 > 格3**（0.270 vs 0.198）：教过的题确实比没教过的答得好，方向与课件一致。
3. **格2 < 格1**（0.192 vs 0.270，掉 29%）：换一种问法就变差——与课件「原题 100% → 换问法 78%」是同一个现象，**说明有一部分学的是问法-答案的配对，不是事实本身**。
4. **误拒答从 2 降到 0**：训练前有两条答「没有相关内容」，训练后不再误拒。

**❌ 但它没学会「答什么」**

1. **数字命中几乎全为 0**（格1–格4 全 0）：模型没能把财报里的具体数字答出来。
2. **训练过的题也会把事实答反**：问"有没有利润分配预案"，金答案是"没有"，训练后模型答成
   "利润分配预案是**适用的**，也就是说要向股东派发现金股利"——**句式学得像，事实是反的**。
   这比"答不出来"更危险：措辞像董秘，内容却是编的。
3. **没训练过的题会编**：问"酒糟、废窖泥怎么处置"，金答案是"交给集团循环经济公司综合利用"，
   模型答成"做生物处理、厌氧发酵、把产物作为饲料投给猪群"——完全是编的（F1 却不算低，0.133）。
4. **格5（RAG 对照）暴露了小模型的另一个短板**：把检索原文的标题行当内容抄了出来
   （输出开头是"境与社会责任·第11页】③固废处理情况…"）——0.6B 分不清"材料"与"回答"的分界。
   唯一非零的数字命中（0.107）恰好出现在这一格，也反过来说明：**事实得靠检索递进来**。

**⚠️ 必须写明的两个方法局限**

1. **字符 F1 奖励"措辞像"，不保证"事实对"**。上面第 2、3 条就是反例：F1 从 0.088 涨到 0.270，
   但其中相当一部分是"学会了董秘腔调"带来的，不能读成"能力提升了 3 倍"。这也是为什么我把
   **数字命中**和**人工看逐条**都保留着。
2. **基座只有 0.6B**（课件用 2B）。容量是硬约束：0.6B 显然不足以在 262 条样本上同时学会口吻与事实。

## 五、结论一句话

> **SFT 能让小模型学会「董秘怎么说」，但学不会「董秘说什么」——事实必须由检索递进窗口，这正好是作业 A 存在的理由。**
> 课件里那句「什么值得背进权重：稳定的风格、口径、格式；什么留在检索库：常更新的事实、长尾细节、需要溯源的证据」，在我们这组数据上被完整复现了一遍。

## 六、没做什么 / 与课件的差异（免得看起来比实际好）

- **没上 GRPO**：作业 B 只要求 SFT（GRPO 是课件的深度五，属于另一条线）。
- **没做参数扫描**：只按课件的量级跑一遍（r=16、3 epoch），没做八种配置对照。
- **基座不是课件同款**：Qwen3-0.6B ≠ Qwen3.5-2B。四格口径一致，但**绝对分数不可与课件直接比**。
- **每格评估有上限**：训练过的格子取前 60 条（不是全部 262/257），测试格是全量（50/46）。
- **漏掉 13 条质检**：那 13 条是模型调用失败（API 余额），重跑 `11_qc_qa.py` 会自动只补这些（有缓存）。
- **人工抽检 40 条仍需你终审**：脚本只做了自动预检 + 模型质检，作业要求的是"人工抽检，删掉编造的"。

## 七、为什么不在 Colab 跑（如实记录）

Colab 那条路被网络卡死：代理节点在 20 分钟内三次在"通/不通"之间翻转
（`colab.research.google.com` 与 `ssl.gstatic.com` 全 000 ↔ 全 200），
表现为「无法加载显示输出所需的 JavaScript 文件」→「卡在正在连接到 T4」→「`await connected: disconnected`」
→「无法连接到代码执行程序」四种报错轮流出。判据脚本留在 `scripts/check_colab_net.sh`：
**全绿 = 浏览器侧问题，有红 = 节点问题**。

最终改用本机 M2 跑（`scripts/23_local_sft_mps.py`），代价是基座从 2B 降到 0.6B，
好处是**完全不依赖网络、不出配额、可复现**——而且四格该有的对照一个不少。
Colab 笔记本（`notebooks/maotai_dongmi_lora.ipynb`）保持可用：网络好时随时可以拿它跑 2B 版本，
把两份结果对照着看（口径一致）。
