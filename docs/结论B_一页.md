# 作业 B 一页结论：用茅台财报训一个「董秘」

> 状态：**造数据、质检、划分、换问法、Colab 笔记本都已完成；四格结果待 Colab 跑完回填。**
> 本文件先写清做法与判分口径，跑完把第 4 节的表填上（数字从 `outputs/B_对照表.md` 抄）。

## 一、语料与数据（做了什么）

| 项 | 数值 |
|---|---|
| 语料 | 贵州茅台 **11 份**：2021–2025 年报 + 2021H1–2026H1 半年报（2026 年报约 2027-04 才披露，故不含） |
| 规模 | 1,292 页 / 48.8 万字正文 / 2,238 张表 → 4,405 块 |
| 造数据 | 一块原文 → 3 组「投资者提问 → 董秘作答」；**强制逐字抄出「依据原文」**（让"编造"变成可字符串校验的） |
| 生成 | 180 + 52 + 92 块，共 **357 条问答**，用时约 5 分钟（deepseek-flash，8 并发，关闭 thinking） |
| 质检 | 阶段一（脚本）：依据原文覆盖率 < 0.9、答案含原文没有的数字、问题像考试题 → 淘汰 6 条；<br>阶段二（模型）：判「有据 0/1/2 · 自然 0/1」→ 留 **293 条**（保留率 82%，全部为「有据 2 且 自然 1」） |
| 划分 | **按块（事实）85/15**：训练 245 条（97 块）/ 测试 48 条（18 块），测试覆盖全部 10 个报告期 |
| 换问法 | 训练集 240 条、测试集 44 条（3-gram Jaccard < 0.5 才算"换了"，否则丢弃） |
| 人工抽检 | 固定种子 `20260924`、按报告期分层抽 **40 条** → `data/sft/review_40.csv`（含块原文，不用翻 PDF 就能判） |

**为什么按块划分而不是按问题划分**：若按问题划分，同一个事实会同时出现在训练集和测试集，
四格的第 3、4 格（"没训练过"）就是假的。所以 `split_manifest.json` 里写死了 `train_chunk_ids` /
`test_chunk_ids`，训练与评测都只读它——物理上杜绝泄漏。

## 二、四格 + 1 对照的定义（跑之前就写死）

|  | 原问法 | 换问法 |
|---|---|---|
| **训练过的块** | 格1 | 格2 |
| **没训练过的块** | 格3 | 格4 |
| **RAG 对照**（同一基座 + 检索到原文） | 格5（在测试集上） | — |

判分：**金标准答案里的数字被答出来的比例**（确定性、可复现）＋ 是否"误拒答"（原文有却说没有）。
课件的参照：训练过原题 2%→100%、训练过换问法 2%→78%、没训练过 0%→0%。

## 三、训练怎么做（Colab 免费 T4）

`notebooks/maotai_dongmi_lora.ipynb` 一次跑完：环境 → 探针（照实际模块名定 LoRA 的 target_modules，
不抄教程）→ **训练前四格 + RAG 对照** → LoRA SFT（r=16、3 epoch、fp16、梯度检查点）→ 训练后四格 → 导出结果。

- 基座：课件同款 `unsloth/Qwen3.5-2B`；**它是 VLM + 混合线性注意力，LoRA 兼容性有风险**，所以笔记本里写了自动降级到 `Qwen/Qwen3-1.7B`。
- 数据直接从本仓库 `data/sft/git/*.jsonl` 拉（去掉了块原文的版本），不用手动上传。
- RAG 对照用的检索上下文由本机 `16_dump_rag_for_b.py` 生成（在**茅台 11 份报告**上检索，
  这样跨年份的测试题不会因为"库里没有"而失真）。

## 五、没做什么（免得看起来比实际好）

- **没上 GRPO**：作业 B 只要求 SFT（课件里 GRPO 是深度五，属于另一条线，本作业不涉及）。
- **没做参数扫描**：只按课件的默认量级（r=16、3 epoch）跑一遍，没有像课件那样做八种配置对照。
- **人工抽检的 40 条需要人终审**：脚本只做了自动预检（依据是否逐字命中）+ 模型质检，
  作业要求是"人工抽检，删掉编造的"——这一步必须由人填 `data/sft/review_40.csv` 的判定列，
  并在 `docs/抽检记录.md` 里写清编造率与处置动作。**脚本不能替你签这个字。**
