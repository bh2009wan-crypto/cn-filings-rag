# 作业 B · 人工抽检记录

> 抽样脚本：`scripts/12_sample_review.py`　抽样种子 `random.Random(20260924)`　样本量 **40**
> 抽检表：`data/sft/review_40.csv`（脚本已把**块原文**填在最后几列，判的时候不用翻 PDF）

## 一、抽样规则（可复现）

1. 从 `data/sft/qa_clean.jsonl`（质检通过的 293 条）里抽，**不是**从原始生成里抽。
2. 按报告期分层，**每份报告至少 3 条**，覆盖 2021–2026 全部 10 个报告期（年报 17 条、半年报 23 条）。
3. 额外强制包含 5 条**边缘样本**（"依据原文"最短 / 答案最长的几条）——这些是最可能藏编造的地方。
4. 判定标准（唯一标准，别放宽）：**答案里任何一个数字、任何一个事实，只要不能在那条「依据原文」或所在块原文里找到，就算编造，删。**

`问题` → `答案` → `依据原文` → `块原文(供核对)`（最后几列，600 字）。
**只填三列**：`判定(留/删)`（写"留"或"删"）、`编造类型`（编数字 / 编事实 / 口径错 / 答非所问）、`备注`。
