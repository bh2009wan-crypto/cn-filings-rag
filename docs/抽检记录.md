# 作业 B · 人工抽检记录

> 抽样脚本：`scripts/12_sample_review.py`　抽样种子 `random.Random(20260924)`　样本量 **40**
> 抽检表：`data/sft/review_40.csv`　执行脚本：`scripts/12b_apply_review.py`（`--apply` 才真删）

## 一、抽样规则（可复现）

1. 从 `data/sft/qa_clean.jsonl`（质检通过的 **312 条**）里抽，**不是**从原始生成里抽。
2. 按报告期分层，**每份报告至少 3 条**，覆盖 2021–2026 全部 10 个报告期（年报 19 条、半年报 21 条）。
3. 额外强制包含 5 条**边缘样本**（"依据原文"最短 / 答案最长的几条）——这些是最可能藏编造的地方。
4. 判定标准（唯一标准，别放宽）：**答案里任何一个数字、任何一个事实，只要不能在那条「依据原文」或所在块原文里找到，就算编造，删。**

## 二、怎么判（10 分钟就能做完）

打开 `data/sft/review_40.csv`，从左往右看这四列就够：
`问题` → `答案` → `依据原文` → `块原文(供核对)`（最后几列，600 字）。
**只填三列**：`判定(留/删)`、`编造类型`、`备注`。

**优先核这 14 条**（脚本自动判定"依据不是逐字摘录"）：序号
`33, 6, 2, 23, 4, 8, 28, 17, 24, 38, 5, 26, 29, 19`
（其中 `6 / 19 / 24 / 28 / 38` 是会计政策类问题——最容易把准则原文引申成自己的话）

## 三、结果

| 指标 | 数值 |
|---|---|
| 抽检条数 | **40** |
| 判定"留" | **26** |
| 判定"删" | **14** |
| **编造率（删 / 抽检）** | **0 / 40 = 0%** |
| 其中因"改写而非逐字引用"弃用 | **14 / 40 = 35%** |

### ⚠️ 一条必须写清的更正

被删的 14 条**经复核没有一条是编造**。用**完整块原文**逐条核对的结果是：

| 核对项 | 结果 |
|---|---|
| 「依据原文」是否逐字出现在原文里 | **40/40 全部命中**（覆盖率 1.00） |
| 答案里的数字能否在原文找到 | **40/40 全部 0 处找不到** |

也就是说：40 条的**事实与数字全部有据**，差别只在**改写幅度**——
答案不是把原文照抄，而是用自己的话复述（这正是"董秘作答"该有的样子）。
被删的 14 条恰好是 `12_sample_review.py` 自动标记为"依据非逐字"的那批，
其中 4 / 5 / 6 / 19 / 24 / 26 / 29 这 7 条的答案对原文的 3-gram 覆盖达 0.62–1.00，
**属于有据甚至接近原文**；反倒是留在集合里的 8 条覆盖不足 0.4，改写幅度更大。

**处置决定（本人确认）**：这 14 条仍**弃用**——理由是"要求训练样本的引用逐字可核"，
属于工程上的保守选择，**不是**因为它们编造。因此：

- 抽检表的 `编造类型` 列填的是 **`改写（非逐字引用）`**，备注写明"复核：依据逐字命中、数字全部可在原文找到 → 非编造"
- 本记录的"编造率"按 **0/40** 记，另记"因改写弃用 14/40"

## 四、典型案例（不是编造，是改写；各举一例）

1. **序号 33（2021H1半年报）**——问"报告期内有没有限售股份变动需要披露？"
   原文：`(二) 限售股份变动情况　□适用 √不适用`
   答案：`没有。限售股份变动情况这一项标注为不适用。`
   → 数字与事实全对，是规范改写。3-gram 覆盖 0.41。

2. **序号 2（2021年报）**——问"营业总收入目标、基本建设投资计划是多少？"
   原文：`今年的经营目标：一是营业总收入较上年度增长15%左右; 二是完成基本建设投资69.69亿元。`
   答案里 15% 与 69.69 亿元**一字不差**，只是加了"这两个数字是董事会定下的年度经营目标"这句自己的话。

3. **序号 17（2023年报）**——问"酱香型系列酒产能建设的投入进度"
   原文给了 `358,316.00 万元`（计划）与 `205,354.57 万元`（已投入）；答案两个数字都对，措辞是自己的。

## 五、自动核对的能力边界（这次学到的）

脚本能查的是"依据/数字在不在原文"，**查不出「事实对但结论错」**——
比如作业 A 里 Q9 那种**口径错**（把母公司报表的数当合并营业收入），数字全都在原文里，脚本会放行。
所以人工这一关真正不可替代的价值是**"读起来对不对"**，而不是"串对不对"。
